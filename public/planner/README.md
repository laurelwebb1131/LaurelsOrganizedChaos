# Laurel's Organized Chaos Planner v2

A free, local-first gothic scrapbook life planner.

## Visual pass v2
- Layered black-paper scrapbook dashboard
- Crooked taped navigation tabs
- Custom crow, owl, moon and star artwork
- Tarot-card navigation
- Torn journal-paper panels
- Hot-pink doodles and ink accents
- Polaroid photo styling
- Richer Today spread
- Custom themed monthly calendar spreads
- Saved drag-and-drop dashboard personalization

## Core planner
- Dashboard, Today, This Week, Calendar, School, Projects, Home & Family, Brain Dump, Goals & Ideas, Life Scrapbook and Settings
- 30/60-minute persistent timer
- Laurel's fixed routine anchors
- task, school and project tracking
- localStorage persistence
- JSON backup/export/import
- Full Chaos / Quieter Chaos modes

## Storage
Planner data is stored in browser localStorage. Use Settings → Export JSON to back up data before clearing browser storage or switching devices.

## Cost
No backend, login, database, paid API or subscription is required for v2.
