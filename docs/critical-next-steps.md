# Critical product hardening sequence

This batch covers the next 20 critical steps for a safe, shippable Hearthwise:

1. API origin policy
2. Nested API validation
3. Expiring rate-limit buckets
4. Stable request IDs and errors
5. Server endpoint tests
6. Frontend companion errors
7. Storage quota error handling
8. Versioned world imports
9. Destructive reset confirmation
10. Desktop CSP
11. Desktop metadata
12. Desktop release commands
13. Dialog semantics
14. Form labels and required states
15. Keyboard navigation
16. Reduced-motion policy
17. GLB loading fallbacks
18. Asset budget documentation
19. CI validation
20. Release notes and external setup documentation

External work still required before production: user authentication, durable multi-user storage, a shared rate-limit store, signed Tauri installers, and deployment secrets.
